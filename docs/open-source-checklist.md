# 开源发布清单

当前代码可以放到 GitHub，但正式公开前建议逐项确认：

- [x] 根目录已有 Apache License 2.0，并在 README 中写明许可证。
- [ ] 将 README 中的 `<your-repository-url>` 替换为真实仓库地址。
- [ ] 检查 Git 历史，确认没有提交 `.env`、SQLite 数据库、备份、真实持仓或个人信息。
- [ ] 补充项目截图或演示 GIF，并确认其中没有个人数据。
- [ ] 决定支持的 Node.js/Next.js 版本，并在 CI 中固定检查 `test`、`lint` 和 `build`。
- [ ] 为公开 issue 配置模板，区分 bug、功能建议和数据口径讨论。
- [ ] 在 `SECURITY.md` 中补充真实的私密漏洞报告渠道。
- [ ] 确认天天基金接口的使用条款、请求频率和对外发布说明符合要求。
- [ ] 评估是否需要认证、反跨站请求伪造保护和备份加密，再决定是否提供公网部署文档。

## 许可证选择

许可证会改变他人能否使用、修改、分发和商用代码，不能由文档自动推断。常见选择包括 MIT、Apache-2.0 和 GPL-3.0；请根据你希望保留的权利和项目依赖情况做出明确选择，或先咨询法律专业人士。
